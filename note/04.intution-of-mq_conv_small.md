# intution of [mq_conv_small](https://github.com/open-quantum-safe/liboqs/blob/main/src/sig/falcon/pqclean_falcon-1024_avx2/vrfy.c#L324-L338)
## References
- [Modulus of Negative Numbers](https://www.youtube.com/watch?v=AbGVbgQre7I)

## The main part of this note.

```
#define Q     12289

/*
 * Reduce a small signed integer modulo q. The source integer MUST
 * be between -q/2 and +q/2.
 */
static inline uint32_t
mq_conv_small(int x) {
    /*
     * If x < 0, the cast to uint32_t will set the high bit to 1.
     */
    uint32_t y;

    y = (uint32_t)x;
    y += Q & -(y >> 31);
    return y;
}
```

`x` must be between -Q/2 and +Q/2 (i.e., between -6144 and +6144, since 12289 / 2 $$\approx$$ 6144.5)

If `x` is non-negative (0 ≤ x ≤ 6144), then `y` = `x`, and return `y` (because y >> 31 = 0, so that Q & -(y >> 31) = 0 and y += Q & -(y >> 31) $$\rightarrow$$ y + 0 = y).

If `x` is negative (-6144 ≤ x < 0), 

  - Generally, $$-a \mod b = b - (a \mod b)$$, where $$a$$ and $$b$$ is positive integer.
  - So, we can write
    - x $$\mod Q$$ = Q - (abs(x) $$\mod Q$$) = Q - abs(x)  (* again, currently `x` is negative, Q is 12289, and since 0 < abs(x) ≤ 6144 $$\rightarrow$$  abs(x) $$\mod Q$$ = abs(x))
  - When `x` is negative, the most significant bit (sign bit) of its 32-bit unsigned integer `y` (i.e `(uint32_t)x`) is `1`, and y >> 31 extracts that sign bit (e.g. 1).
  - So, -(y >> 31) = -1.
  - -1 as a 32-bit unsigned integer is 0xFFFFFFFF (all bits set to 1) in two's complement.
  - So,

$$\hspace{2em}$$ y += Q & -(y >> 31)

$$\hspace{2em}$$ $$\Rightarrow$$ y + (Q & -(y >> 31))

$$\hspace{2em}$$ $$\Rightarrow$$ y + Q & -1

$$\hspace{2em}$$ $$\Rightarrow$$ y + Q & 0xFFFFFFFF

$$\hspace{2em}$$ $$\Rightarrow$$ y + Q, which is `Q - abs(x)`
